# 📰 Утренний новостной дайджест

Автоматический агент: каждое утро собирает новости за прошедшие сутки по заданным
темам из RSS-лент, саммаризирует через Claude API и присылает в Telegram.
Работает на бесплатных GitHub Actions — **свой сервер не нужен**.

## Темы (настроены в `news.py`, словарь `TOPICS`)
- Искусственный интеллект
- Энергетика
- Т Плюс / Энергосбыт Плюс (фильтр по ключевым словам)
- Интеллектуальные системы учёта (ИСУ)
- Информационная безопасность
- Новинки в ИТ
- Новости правительства РФ

## Установка (10 минут, один раз)

### Шаг 1. Создай репозиторий
1. Зайди на https://github.com → **New repository**.
2. Назови, например, `news-digest`. Можно сделать **Private**.
3. Создай его (пустым, без README).

### Шаг 2. Залей файлы
Самый простой путь — через веб-интерфейс:
- На странице репозитория: **Add file → Upload files**, перетащи `news.py`,
  `requirements.txt`, `README.md`.
- Папку `.github/workflows/` создать через веб тоже можно: **Add file →
  Create new file**, в имени напиши `.github/workflows/news.yml` (слэши сами
  создадут папки) и вставь содержимое файла.

Либо через git:
```bash
git init
git add .
git commit -m "news digest agent"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/news-digest.git
git push -u origin main
```

### Шаг 3. Получи токены

**Anthropic API key:**
- https://console.anthropic.com → API Keys → Create Key.
- Пополни баланс (дайджест стоит копейки — несколько центов в день).

**Telegram bot token:**
- У тебя уже есть бот `@VESTI_ME_BOT`. Токен — у @BotFather:
  напиши ему `/mybots` → выбери бота → **API Token**.
  (Если токен потерян — `/token`.)

**Telegram chat_id (куда слать):**
1. Открой своего бота в Telegram и нажми **Start** / напиши ему любое сообщение.
2. Открой в браузере (вставь токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. Найди в ответе `"chat":{"id":...}` — это число и есть твой `chat_id`.
   (Если шлёшь в канал/группу — там id с минусом, тоже подойдёт; бот должен
   быть участником/админом.)

### Шаг 4. Добавь секреты в репозиторий
В репозитории: **Settings → Secrets and variables → Actions → New repository
secret**. Создай три штуки (имена строго такие):

| Имя секрета          | Значение                       |
|----------------------|--------------------------------|
| `ANTHROPIC_API_KEY`  | твой ключ Anthropic            |
| `TELEGRAM_TOKEN`     | токен бота от BotFather         |
| `TELEGRAM_CHAT_ID`   | твой chat_id (число)            |

### Шаг 5. Проверь вручную
**Actions** (вкладка вверху) → выбери `morning-news-digest` слева →
кнопка **Run workflow**. Через минуту дайджест должен прийти в Telegram.
Логи запуска видны там же — если что-то не так, в них будет причина.

## Настройки

- **Время рассылки** — в `.github/workflows/news.yml`, строка `cron`.
  Сейчас `0 4 * * *` = 04:00 UTC = **07:00 МСК**. Время в cron всегда UTC,
  для МСК вычитай 3 часа.
- **Темы и источники** — словарь `TOPICS` в `news.py`. Добавляй/убирай RSS-ленты.
- **Ключевые слова фильтра** — словарь `TOPIC_KEYWORDS` (для Т Плюс и ИСУ,
  где общие отраслевые ленты фильтруются по релевантности).
- **Глубина окна** — `HOURS_BACK` (по умолчанию 26 ч ≈ сутки с запасом).

## Стоимость
- GitHub Actions: бесплатно (приватный репозиторий — 2000 минут/мес, запуск ~1 мин).
- Anthropic API: несколько центов за дайджест.
- Telegram: бесплатно.
